# KingVet Animal Clinic website concept

This is a separate, presentation-ready website concept created from the KingVet Animal Clinic Facebook screenshots supplied in this conversation. It does not replace the prior generic veterinary demo.

## What is real vs. placeholder

- **Used from the supplied reference:** clinic name, orange/sky-blue brand direction, tagline, Quezon City/Roosevelt Avenue location, public phone/email, and listed 24/7 availability.
- **Original website work:** responsive layout, interface, page copy, CTA flow, form behavior, and a generated hero image.
- **Must verify before launch:** exact street address, confirmed operating/emergency policy, all service details, staff, testimonials, map, and appointment workflow.
